Artículo 31. Cuando este Código u otras leyes no señalen plazo para la práctica de alguna actuación o para el ejercicio de un derecho, se tendrán señalados los siguientes:
I. Quince días para desahogo de pruebas; y
II. Tres días para cualquier otro caso.
La autoridad deberá hacer del conocimiento del interesado dichos plazos.
