Artículo 500.- Para el caso de divisiones de fincas, lotes baldíos y predios, la Dirección asignará nuevo número oficial para cada una de las fracciones, para lo cual se conservará el número arábigo ya asignado y a las siguientes fracciones se le asignará el mismo número arábigo seguido de la letra "A" y la que le siga conforme al abecedario, según el número de fracciones de que se trate.
Para el caso de una fusión de dos o más fincas, lotes baldíos o predios, se dejará un solo número oficial.
