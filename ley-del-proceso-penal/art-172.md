Artículo 172. Las partes pueden proponer datos o medios de prueba con el fin de sustentar la imposición, revisión, sustitución, modificación o cese de una medida cautelar.
Estos datos o medios de prueba se conservarán en un registro especial cuando no esté permitida su incorporación al debate del juicio oral.
Para este efecto, el Juez de Control convocará a una audiencia pública para oír a las partes o para recibir los medios de prueba.
En la audiencia el juez valorará la prueba conforme a las normas que para el efecto contiene esta ley, con el exclusivo propósito de fundar la decisión que se asuma sobre la medida cautelar.
