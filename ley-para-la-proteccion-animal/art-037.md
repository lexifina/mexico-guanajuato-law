Artículo 37. Para el adiestramiento o entrenamiento de animales, queda prohibido utilizar técnicas que les causen sufrimiento, así como emplear métodos de castigo como golpes o prácticas de maltrato animal. Para verificar la agresividad de animales queda prohibido utilizar para dicho fin a otros animales vivos, así como las técnicas o métodos antes señalados.
(REFORMADA SU DENOMINACIÓN, P.O. 2 DE AGOSTO DE 2024)
